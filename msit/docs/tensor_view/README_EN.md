# msit tensor view Usage Guide

## Introduction

The tensor-view tool provides an interface for viewing tensors. The source data is the bin file generated after dump. It supports chained slicing and transpose operations. By default, statistical information and tensor.shape are printed each time. You can choose to print the tensor itself and save it to a file. The file format can be standard torch format or ATB format (the same as the one generated by dump).

Windows is not supported currently.

## Tool Installation

### Installation Prerequisites

- Install the Ascend AI inference-related driver, firmware, and CANN package for the development and running environment. Refer to [CANN](https://www.hiascend.com/cann/download).
- After installation, you can specify the installed CANN version path by **setting the CANN_PATH environment variable**, for example: export CANN_PATH=/xxx/Ascend/ascend-toolkit/latest.
- If not set, the tool attempts to obtain the CANN version from the environment variable ASCEND_TOOLKIT_HOME and the path /usr/local/Ascend/ascend-toolkit/latest respectively.

### Installation Methods

The installation methods include: **source code installation** and **pip source installation**. You can choose as needed.

- [Source code installation](#source-code-installation): Install from source code to ensure the latest msit functionality.
- [pip source installation](#pip-source-installation): Install the msit package through pip. Packages are released once a quarter.

#### Source Code Installation

```shell
git clone https://gitcode.com/Ascend/msit.git
# 1. git pull origin to update the latest code
cd msit/msit

# 2. Install the msit package
pip install .

# 3. Install tensor-view:
msit install tensor-view

# 4. After installation, use the msit check command to verify the installation:
msit check tensor-view
```

#### pip Source Installation

```shell
# 1. Install the msit package
pip install msit

# 2. Install tensor-view:
msit install tensor-view

# 3. After installation, use the msit check command to verify the installation:
msit check tensor-view
```

## Data Preparation

The tensor parameter file (.bin/.pth) path supports ATB format (.bin) and Torch format (.pth).

## Command Samples

```sh
# Input an ATB file, apply consecutive slice, transpose, slice, and transpose operations. The operations are for demonstration only. This sample will fail because the first transpose [0,2,1,4] is invalid.
msit tensor-view --bin intensor0.bin --operations "[1:2, ..., 3::2];(0,2,1,4);[1:3];(2,0,1)" --output tmp_view/output_view.bin
```

```sh
# Input a PTH file, output an ATB format file, using abbreviated parameter names
msit tensor-view -b rand.pth -op "[1];(2,0,1)" -o out/processed_rand.bin
```

## Parameter Description

| Parameter               | Description                                                                                                                                                                                                                                                       | Required |
|-------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|----|
| --bin, -b         | Tensor parameter file path. Supports ATB format (.bin) and Torch format (.pth).                                                                                                                                                                                                                 | Yes  |
| --print, -p       | Whether to print the tensor to the console. By default, it is not printed. Note that the print operation occurs after operations.                                                                                                                                                                                                            | No  |
| --operations, -op | The string for tensor slicing and permute operations. It must be enclosed in **double quotes**. Multiple operations are separated by **;**. Slicing operations must be enclosed in **[ ]**, and transpose operations must be enclosed in **( )**. These operation strings are applied to the tensor in order. During execution, the tool checks whether the slicing and transpose strings are valid, whether the slicing index is out of bounds, and whether the transpose string corresponds to the dimensions. Note that slicing supports **standard slicing**, **numeric indexing**, and **Ellipsis**. These three forms can be freely combined in an extended slice. True/False and other forms of slicing are not supported. | No  |
| --output, -o      | The storage path for the processed tensor. There is no default value. When the file extension is .bin, it is saved in ATB format. When the file extension is .pth, torch.save is used. If the extension is omitted, the save format is consistent with the format of [--bin].                                                                                                                                                      | No  |
| -h, --help        | Tool usage help information.                                                                                                                                                                                                                                                 | No  |
